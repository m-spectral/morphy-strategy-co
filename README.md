# Morphy Strategy & Co. website

A static, four-page website. No build step, framework, or server is required for GitHub Pages.

## Contents

- `index.html` — home
- `work.html` — Research, Advisory, Learning, and Labs
- `labs.html` — Omega Centauri and Andromeda
- `about.html` — Morphy ethos and working principles
- `assets/style.css` — styles and light/dark themes
- `assets/site.js` — theme toggle, menu, filters, and reveal behavior
- `assets/images/` — images currently used by the pages
- `.nojekyll` — serves the static files directly on GitHub Pages

## Publish on GitHub Pages

Upload the **contents of this folder** to the root of a GitHub repository, keeping `index.html` at the root. In the repository's **Settings → Pages**, choose **Deploy from a branch**, then select the branch containing these files and **/(root)** as the folder. No workflow or build command is needed.

The page and asset links are relative, so the site can work as either a user site or a project site. For current GitHub instructions, see [Configuring a publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Preview locally

Open `index.html`, or serve this folder with any local static-file server and open its root URL.

## Before publishing

Confirm the public contact address. The footer currently uses `bmunoz@morphystrategyco`, as supplied for this draft.

Google Fonts and the external profile, donation, Obsidian, and GitHub links require an internet connection. There are no analytics, forms, or server-side services.
